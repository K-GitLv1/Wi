Bootstrap คือ

Bootstrap คือเฟรมเวิร์ก CSS ที่ช่วยให้การสร้างเว็บเป็นไปอย่างรวดเร็วและง่ายดาย โดยใช้คลาสต่างๆ สำหรับการจัดการโครงสร้างและการตกแต่งหน้าเว็บ เช่น การจัดตำแหน่ง, สี, และขนาดต่างๆ

CSS คือ

CSS (Cascading Style Sheets) คือภาษาในการตกแต่งและออกแบบหน้าเว็บ ซึ่งช่วยให้สามารถกำหนดรูปแบบการแสดงผลของ HTML เช่น สี ขนาดของตัวอักษร การจัดตำแหน่ง และอื่นๆ

JavaScript คือ

JavaScript คือภาษาโปรแกรมที่ใช้ในการเพิ่มฟังก์ชั่นและการโต้ตอบในเว็บไซต์ เช่น การตรวจสอบข้อมูลที่ผู้ใช้กรอกในฟอร์ม หรือการแสดงผลข้อมูลแบบไดนามิก

HTML คือ

HTML (HyperText Markup Language) คือภาษาในการสร้างโครงสร้างของเว็บไซต์ เช่น การจัดระเบียบเนื้อหาให้มีลำดับที่ชัดเจน และแสดงผลข้อความ รูปภาพ ลิงก์ และฟอร์มต่างๆ
